feat(packaging): 打包为 Windows 可执行文件（PyInstaller，onedir + onefile）

产物（dist/wjx-auto/，116 MB）
- wjx-auto-gui.exe   图形界面，双击即用（无控制台窗口）
- wjx-auto.exe       命令行版（selftest/probe/fill/autostart/daemon/bank/check-env）
- 使用说明.txt        随包分发的上手文档 + 常见问题
- _internal/         Python 3.15 运行时 + selenium 4.51 + 内置 Edge 驱动

打包实现（packaging/）
- wjx-auto.spec：一个 spec 同时构建 GUI 与 CLI 两个 exe，共用同一份 Analysis，
  体积几乎不翻倍（此前两个 spec 各自 COLLECT 会互相覆盖）
- wjx-auto-onefile.spec：单文件便携版
- common.py：只收集 selenium 及其运行依赖，排除 numpy/pandas/matplotlib/lxml 等，
  驱动只收 drivers/*.exe（跳过 11MB 的 edgedriver.zip）
- tools/build_exe.py：一键构建，PyInstaller 缓存与临时目录落在项目内（受限环境可写），
  构建前默认先跑一遍自测，构建后补齐使用说明并打印体积报告

为打包做的适配
- paths.py：检测 sys.frozen；只读资源取 _MEIPASS，可写数据取 exe 同级目录，
  exe 目录不可写时回落到 LOCALAPPDATA；驱动查找覆盖 _internal/drivers 与 exe 同级
  drivers（strict 模式不再用另一个浏览器的驱动顶替）
- 新增 wjx/htmlparse.py：纯标准库 HTML 解析器（find_all/select/get_text/next_sibling），
  取代 bs4+lxml，省约 30MB；probe --static 在打包版照常可用
- mockserver.ensure_running：打包后没有 main.py 可执行，改为本进程内线程启动模拟服务
- 新增 check-env 命令：报告运行方式/可写目录/tkinter/解析器/selenium/浏览器与驱动/
  网络/答案库/任务，换机器先跑它定位问题
- 模拟问卷 HTML 改为复刻真实问卷星模板（fieldset + div.field[data-role=fieldcontain]
  + div.topichtml + #ctlNext），题干去掉题号前缀，与真实解析路径一致
- 默认答案库补上配套例题答案，开箱即可跑通 demo

顺带修掉的 bug
- backend=auto 时，模拟问卷网址（127.0.0.1）被解析为 mock 后端，但预打开分支只比较
  配置字符串 mock，导致为模拟问卷启动真实浏览器（实测拉起 19 个 msedge 进程）；
  改为按 resolve_backend() 的解析结果判断
- 默认示例任务关闭 preopen，避免首次启动就尝试打开浏览器
- 自测"必填缺失判校验失败"未固定 auto_answer，被答案库自动补齐而误判，现已显式关闭

- probe 用内置驱动启动真实无头 Edge 读出真实问卷 5 道题
